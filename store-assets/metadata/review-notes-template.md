# Reviewer Notes Template

Fitness Tracker can be reviewed without creating an account.

Suggested review path:

1. Open Home and select Browse exercises.
2. Search for Bench Press and open the exercise to view its motion demonstration and instructions.
3. Open Workout, select the Push Day routine, and start a workout.
4. Enter set values, complete a set, and inspect the rest timer.
5. Finish the workout to view its summary, then open History.
6. Return to Workout and use Create routine to inspect the routine builder.

Core workout and history data is stored locally on the device. No paid content or external hardware is required for review.
